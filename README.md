### 🧶 Handmade Marketplace API

A backend API for a handmade products marketplace built with NestJS. The platform enables users to create accounts, open their own shops (became sellers), manage handmade product listings, ordering and payment, with administrative tools for managing marketplace content.

#### 🚀 Technologies

- Backend: NestJS, TypeScript
- Database: PostgreSQL
- ORM: Prisma
- Caching: Redis
- Authentication: JWT
- Containerization: Docker

#### ✨ Features

- Authentication & Authorization: Secure authentication and role-based access control.
- User Management: User registration and account management.
- Seller Shops: Create and manage seller profiles and shop information.
- Product Management: Create, update, delete, and manage product listings.
- Category Management: Organize products into categories with administrative controls.
- Admin Management: Administrative operations and protected admin functionality.
- Caching: Redis integration for improved performance.
- Search & Filtering: Find products efficiently.
- Pagination: Retrieve large datasets in manageable pages.
- Docker Support: Containerized development environment for the application and its dependencies.
