### 🧶 Handmade Marketplace API

A backend API for a handmade products marketplace built with NestJS. The platform enables users to create accounts, open their own shops, and manage handmade product listings, with administrative tools for managing marketplace content.

#### 🚀 Technologies

- Node.js – JavaScript runtime
- NestJS – Backend framework
- TypeScript – Type-safe development
- PostgreSQL – Relational database
- Prisma ORM – Database access and management
- Redis – Caching and performance optimization
- JWT – Authentication
- Docker – Application and services containerization

#### ✨ Features

- Authentication & Authorization – Secure authentication and role-based access control.
- User Management – User registration and account management.
- Seller Shops – Create and manage seller profiles and shop information.
- Product Management – Create, update, delete, and manage product listings.
- Category Management – Organize products into categories with administrative controls.
- Admin Management – Protected administrative operations.
- Redis Caching – Improve response times and reduce unnecessary database queries.
- Product Search & Filtering – Find products based on relevant criteria.
- Pagination – Retrieve large datasets efficiently.
- Docker Support – Run the application and its dependencies in containers.
